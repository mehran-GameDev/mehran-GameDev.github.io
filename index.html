Pong Arcade Classic

Completed

A recreation of Pong with angle-based ball deflection, a bot opponent and a decoupled scoring system.

What I built

  • Vector reflection with deflection angles that depend on where the ball hits the paddle.
  • A bot opponent that tracks the ball with simulated reaction delay.
  • An event-driven score and audio controller, separate from game logic.

Goal

Learn collision handling and tune game feel by recreating a classic with clean, reusable code.

Flappy Bird Runner

Completed

A one-touch runner with tuned jump physics, endless obstacles through object pooling and saved high scores.

What I built

  • Object pooling so obstacles are reused instead of created and destroyed.
  • Impulse-based jump curves tuned for a consistent feel.
  • JSON serialization to keep high scores between sessions.

Goal

Practice memory-conscious design and frame-rate independent movement.
